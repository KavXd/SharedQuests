# Changelog

This project uses [Semantic Versioning](https://semver.org/).

## 1.0.0 - 2026-11-19

First release.

- Shared quest accepts, kills and other counters, finished steps and hand-ins.
- A quest one player finishes becomes ready to turn in for the others; each player gets their own rewards.
- Same dailies and weeklies for the group, including rerolls.
- Optional sync of the EFT 1.2 story from the VisitAPI mod.
- Optional Fika support: kills from a raid played together are counted once.
